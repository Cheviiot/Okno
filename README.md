# Okno

**Удалённый рабочий стол для локальной сети.** Без серверов ID, relay и облачных
аккаунтов: устройства находят друг друга в LAN и соединяются напрямую.

Okno — самостоятельная реализация идеи [SubnetDesk](https://github.com/zibo-chen/SubnetDesk),
написанная с нуля на Rust. Интерфейс общий на Slint и подстраивается под систему:
в GNOME выглядит как Adwaita, в Windows 11 — как Fluent.

> Статус: ранняя разработка. Готовы сетевой слой, вход и обнаружение (этап 1);
> экран, ввод и интерфейс — в работе.

## Возможности

| | Статус |
|---|---|
| Прямое подключение по IP или имени, порт 21200 | готово |
| Шифрование Noise_XX, отпечаток ключа хоста (TOFU) | готово |
| Логин и пароль хоста (Argon2id), задержка после неудачных попыток | готово |
| Список разрешённых подсетей | готово |
| Обнаружение в LAN: mDNS `_okno._tcp` и UDP-broadcast | готово |
| Wake-on-LAN | готово |
| Экран, мышь и клавиатура | в работе |
| Буфер обмена, передача файлов | план |
| Звук, терминал, проброс портов | план |
| Приложение на Slint (Adwaita / Fluent) | план |

Работа через интернет не поддерживается и не планируется: для этого запускайте
Okno поверх WireGuard, Tailscale или OpenVPN. Адреса CGNAT (`100.64.0.0/10`,
Tailscale) по умолчанию разрешены.

## Командная строка

```sh
okno-cli id                                   # имя и отпечаток устройства
echo 'пароль' | okno-cli set-password --user me
okno-cli host                                 # принимать подключения
okno-cli discover                             # найти хосты в сети
echo 'пароль' | okno-cli connect desk --user me --trust
okno-cli wake aa:bb:cc:dd:ee:ff
```
