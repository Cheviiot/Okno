# Okno

**Удалённый рабочий стол для локальной сети.** Без серверов ID, relay и облачных
аккаунтов: устройства находят друг друга в LAN и соединяются напрямую.

Okno — самостоятельная реализация идеи [SubnetDesk](https://github.com/zibo-chen/SubnetDesk),
написанная с нуля на Rust. Интерфейс общий на Slint и подстраивается под систему:
в GNOME выглядит как Adwaita, в Windows 11 — как Fluent.

> Статус: ранняя разработка. Работают подключение, вход, обнаружение, экран и
> ввод, звук, буфер обмена, файлы, терминал, проброс портов и приложение с
> интерфейсом по GNOME HIG (Fluent в Windows). Впереди — упаковка.

## Возможности

| | Статус |
|---|---|
| Прямое подключение по IP или имени, порт 21200 | готово |
| Шифрование Noise_XX, отпечаток ключа хоста (TOFU) | готово |
| Логин и пароль хоста (Argon2id), задержка после неудачных попыток | готово |
| Список разрешённых подсетей | готово |
| Обнаружение в LAN: mDNS `_okno._tcp` и UDP-broadcast | готово |
| Wake-on-LAN | готово |
| Экран (H.264), мышь и клавиатура: GNOME через порталы, Windows через WGC и SendInput | готово |
| Буфер обмена (текст) в обе стороны | готово |
| Передача файлов: отправка в «Загрузки», просмотр и скачивание файлов хоста, SHA-256 | готово |
| Удалённый терминал (окно в стиле GNOME Console) | готово |
| Проброс TCP-портов | готово |
| Звук с удалённого компьютера (Opus) | готово |
| Приложение на Slint: Adwaita в GNOME, Fluent в Windows 11, русский перевод | готово |

Работа через интернет не поддерживается и не планируется: для этого запускайте
Okno поверх WireGuard, Tailscale или OpenVPN. Адреса CGNAT (`100.64.0.0/10`,
Tailscale) по умолчанию разрешены.

## Приложение

`okno` — окно с тремя разделами:

- **Устройства** — найденные в сети компьютеры, подключение по адресу,
  доверенные устройства.
- **Этот компьютер** — разрешить управление, отпечаток, логин и пароль,
  подключённые сейчас.
- **Настройки** — имя устройства.

При первом подключении Okno показывает отпечаток ключа хоста — сверьте его с
разделом «Этот компьютер» на том компьютере. В окне сессии клавиатура целиком
уходит на удалённый компьютер; F11 — полный экран.

## Командная строка

```sh
okno-cli id                                   # имя и отпечаток устройства
echo 'пароль' | okno-cli set-password --user me
okno-cli host                                 # принимать подключения (спросит доступ к экрану)
okno-cli host --test-pattern                  # то же с тестовой картинкой
okno-cli discover                             # найти хосты в сети
echo 'пароль' | okno-cli connect desk --user me --trust
echo 'пароль' | okno-cli connect desk --user me --frames 60 --snapshot shot.png
okno-cli wake aa:bb:cc:dd:ee:ff
```
