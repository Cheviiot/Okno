# Okno

**Удалённый рабочий стол для локальной сети.** Без серверов ID, relay и облачных
аккаунтов: устройства находят друг друга в LAN и соединяются напрямую.

Okno — самостоятельная реализация идеи [SubnetDesk](https://github.com/zibo-chen/SubnetDesk),
написанная с нуля на Rust. Интерфейс общий на Slint и подстраивается под систему:
в GNOME выглядит как Adwaita, в Windows 11 — как Fluent.

> Статус: первый выпуск 0.1.0, ранняя версия. Работают подключение, вход,
> обнаружение, экран и ввод, звук, буфер обмена, файлы, терминал, проброс
> портов, виртуальный экран. Об ошибках пишите в
> [Issues](https://github.com/Cheviiot/Okno/issues).

## Возможности

| | Статус |
|---|---|
| Прямое подключение по IP или имени, порт 21200 | готово |
| Шифрование Noise_XX, отпечаток ключа хоста (TOFU) | готово |
| Логин и пароль хоста (Argon2id), задержка после неудачных попыток | готово |
| Список разрешённых подсетей | готово |
| Обнаружение в LAN: mDNS `_okno._tcp` и UDP-broadcast | готово |
| Wake-on-LAN | готово |
| Экран (H.264), мышь и клавиатура: GNOME через порталы, Windows через WGC и SendInput | готово |
| Буфер обмена (текст) в обе стороны | готово |
| Передача файлов: отправка в «Загрузки», просмотр и скачивание файлов хоста, SHA-256 | готово |
| Удалённый терминал (окно в стиле GNOME Console) | готово |
| Проброс TCP-портов | готово |
| Звук с удалённого компьютера (Opus) | готово |
| Виртуальный экран выше разрешения монитора (хост Windows, Virtual Display Driver) | готово, проверяется на Windows |
| Приложение на Slint: Adwaita в GNOME, Fluent в Windows 11, русский перевод | готово |

Работа через интернет не поддерживается и не планируется: для этого запускайте
Okno поверх WireGuard, Tailscale или OpenVPN. Адреса CGNAT (`100.64.0.0/10`,
Tailscale) по умолчанию разрешены.

## Установка

Готовые сборки лежат на странице [выпусков](https://github.com/Cheviiot/Okno/releases):
`okno-<версия>-windows-x86_64.zip` и `okno-<версия>-linux-x86_64.tar.zst`.

### Windows 10/11

1. Скачайте zip и распакуйте, например, в `C:\Program Files\Okno` или в
   любую папку.
2. Запустите `okno.exe`. Windows SmartScreen может предупредить о неизвестном
   издателе (сборка не подписана): «Подробнее» → «Выполнить в любом случае».
3. Когда на этом компьютере впервые включается «Разрешить удалённое управление»,
   брандмауэр Windows спросит о доступе к сети — разрешите для **частных
   сетей**. Сеть в «Параметры → Сеть и Интернет» должна быть частной, иначе
   компьютеры не увидят друг друга.

### Linux (x86_64, GNOME)

```sh
tar xf okno-0.1.0-linux-x86_64.tar.zst && cd okno-0.1.0-linux-x86_64
./scripts/install.sh --prefix ~/.local --target-dir bin     # для себя, без sudo
# или для всех: sudo ./scripts/install.sh --prefix /usr --target-dir bin
```

Okno появится в меню приложений. Нужны PipeWire и `xdg-desktop-portal-gnome`
(в GNOME они есть). Если включён брандмауэр (firewalld, ufw), откройте порты
**21200/tcp** и **21201/udp**.

Flatpak собирается локально из `packaging/flatpak/io.github.cheviiot.okno.yml`,
рецепт для каталога Nivora (ALT Linux) — `packaging/stapler/Staplerfile`.

## Быстрый старт

На компьютере, которым будут управлять (хост):

1. Откройте Okno → **Этот компьютер**, задайте имя пользователя и пароль.
2. Включите **Разрешить удалённое управление**. В GNOME система один раз спросит, какой
   экран показывать и можно ли управлять вводом, — разрешите и отметьте
   «Запомнить». В Windows ничего спрашивать не будет.
3. По умолчанию при каждом подключении хост спрашивает разрешения у того, кто
   сидит за ним. Для компьютера без человека выключите «Спрашивать перед каждым
   подключением».

На компьютере, с которого управляют (клиент):

1. Откройте Okno → **Устройства**: хосты этой сети появятся в списке сами. Если
   нет — введите IP-адрес хоста в «Подключение по адресу».
2. При первом подключении сверьте отпечаток ключа с тем, что показан в
   разделе «Этот компьютер» на хосте, и примите его.
3. Введите имя пользователя и пароль хоста. Пароль можно запомнить — он хранится в
   системной связке ключей.

Каждая машина может быть и хостом, и клиентом одновременно.

## Приложение

`okno` — окно с тремя разделами:

- **Устройства** — найденные в сети компьютеры, подключение по адресу,
  доверенные устройства.
- **Этот компьютер** — разрешить удалённое управление, отпечаток, имя пользователя и пароль,
  подключённые сейчас.
- **Настройки** — имя устройства.

При первом подключении Okno показывает отпечаток ключа хоста — сверьте его с
разделом «Этот компьютер» на том компьютере. В окне сессии клавиатура целиком
уходит на удалённый компьютер; F11 — полный экран. В меню сессии можно выключить
«Масштабировать по окну» — тогда экран показывается пиксель в пиксель и
сдвигается вслед за указателем.

### Виртуальный экран (хост Windows)

Хост на Windows может на время сессии перенести рабочий стол на виртуальный
монитор с разрешением больше, чем у настоящего, например 3840×2160 на
мониторе 1920×1080. Для этого на хосте один раз установите подписанный драйвер
[Virtual Display Driver](https://github.com/VirtualDrivers/Virtual-Display-Driver)
(установщик на странице выпусков). Его разрешения задаются в
`C:\VirtualDisplayDriver\vdd_settings.xml`, по умолчанию 1920×1080,
2560×1440 и 3840×2160.

После этого в списке экранов окна сессии появятся пункты «Виртуальный экран
W×H». На время их использования Okno делает виртуальный монитор основным и
отключает настоящие; при переключении обратно или по окончании сессии прежняя
раскладка экранов возвращается. Если Okno аварийно завершится, раскладка
восстановится при следующем запуске, а до того — сочетанием Win+P.

## Командная строка

```sh
okno-cli id                                   # имя и отпечаток устройства
echo 'пароль' | okno-cli set-password --user me
okno-cli host                                 # принимать подключения (спросит доступ к экрану)
okno-cli host --test-pattern                  # то же с тестовой картинкой
okno-cli discover                             # найти хосты в сети
echo 'пароль' | okno-cli connect desk --user me --trust
echo 'пароль' | okno-cli connect desk --user me --frames 60 --snapshot shot.png
okno-cli wake aa:bb:cc:dd:ee:ff
```
