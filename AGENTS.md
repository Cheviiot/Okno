# Инструкции для агентов Okno

## Язык
- С пользователем — по-русски. Код, идентификаторы, коммиты и комментарии — по-английски.

## Окружение
- Все сборки и тесты — в Distrobox `okno-dev` (Fedora 44), см. `docs/development.md`.
  На хост ALT зависимости проекта не ставить.
- Проверочная сборка под Windows: `cargo build --workspace --target x86_64-pc-windows-gnu`
  в том же контейнере. Настоящая проверка UI и захвата — только на Windows 11.

## Проверки перед коммитом
- `cargo fmt --all`, `cargo clippy --workspace --all-targets` без предупреждений,
  `cargo test --workspace`, кросс-сборка под Windows.

## Правила
- GUI и захват экрана проверять только на виртуальном дисплее: безголовый
  `gnome-shell --headless` или `mutter --headless` со своей D-Bus-сессией.
  Не открывать тестовые окна и не снимать экран на основном дисплее пользователя.
- Тесты не пишут в настоящий конфиг: `OKNO_CONFIG_DIR` на временный каталог,
  `OKNO_DOWNLOAD_DIR`/`OKNO_INCOMING_DIR` — на временные каталоги.
- Контейнер видит PipeWire и порталы пользователя. В ручных и E2E-прогонах
  приложения ставить `OKNO_NO_SOUND=1` и `OKNO_NO_KEYRING=1` (иначе пароли
  попадут в настоящую связку ключей), хост запускать с `--test-pattern` (звук —
  тестовый тон), не нажимать «Выбрать файлы…» и не включать хост с настоящим
  захватом экрана: диалоги порталов и звук попадут на реальный рабочий стол.
- Протокол: номера полей в `okno-proto` не переиспользовать; изменение
  проводного формата — повод поднять `PROTOCOL_VERSION` и обновить `docs/protocol.md`.
- Пароли и ключи не логировать; пароль в памяти хранить в `Zeroizing`.
- Linux-хост работает только через XDG-порталы (ScreenCast, RemoteDesktop,
  Clipboard), без root и без прямого доступа к `/dev/uinput`.
